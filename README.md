# DustHeal — удаление пыли, пятен и грязи с фотографий

Программа для Windows 10/11 (64 бит). Убирает с фотографий следы пыли и грязи на матрице, линзах объектива
и светофильтрах. Фон на месте пятна восстанавливается плавно, без следов: небо, водная гладь, стены, светлые
поверхности. Есть пакетная обработка: пятна отмечаются один раз и автоматически убираются на сотнях снимков.

## Возможности

| | |
|---|---|
| **Три алгоритма + «Авто»** | **Пыль**: снимает тень пятна, детали и родное зерно под ним остаются. **Восстановление**: переносит текстуру с лучшего соседнего участка и подгоняет цвет и яркость по Пуассону. **Плавная заливка**: идеально гладкий градиент плюс естественное зерно. В режиме «Авто» метод выбирается для каждого пятна по анализу пятна и фона вокруг. |
| **Автопоиск пятен** | Многомасштабный детектор тёмных (по желанию и светлых) мягких пятен на однородном фоне. Настраиваются чувствительность и диапазон размеров. |
| **Инструменты** | «Точка» (клик), «Кисть» (мазок для волосков и царапин), меню пятна по ПКМ (удалить, сменить метод, изменить размер), отмена и повтор, сравнение «до/после». |
| **Пакетная обработка** | Карта пятен переносится на любые снимки: другого размера, повёрнутые, с другим сюжетом и экспозицией. На каждом кадре **уточняются положение и размер пятна**, а **цвет, яркость, контраст и зерно фона берутся из окружения пятна на этом же кадре**. Обработка идёт в несколько потоков. |
| **Качество файлов** | JPEG, TIFF и PNG в 8 и 16 бит, BMP и WebP. Сохраняются EXIF и ICC-профиль, JPEG пишется без цветовой субдискретизации (4:4:4). Работают пути с кириллицей. |
| **Консольный режим** | Пакет можно запускать из скриптов, без интерфейса. |

## Установка

### Вариант А: готовый exe
Соберите exe одним из способов ниже. Получится папка `DustHeal` с файлом `DustHeal.exe`. Это портативная версия:
установка не нужна, папку можно положить куда угодно.

**Сборка на своём ПК:**
1. Установите Python 3.12 (64-bit) с https://www.python.org/downloads/windows/ и при установке отметьте
   **«Add python.exe to PATH»**.
2. Дважды щёлкните `build.bat`. Первая сборка занимает 3–5 минут.
3. Готовая программа: `dist\DustHeal\DustHeal.exe`.

**Сборка через GitHub без установки Python:** загрузите проект в репозиторий GitHub. Workflow
`.github/workflows/build-windows.yml` сам соберёт и проверит exe на Windows. Скачайте архив
`DustHeal-win64` на вкладке Actions → последний запуск → Artifacts.

### Вариант Б: запуск из исходников
Запустите `run.bat`. Он один раз установит зависимости, после этого программа открывается сразу.

## Как пользоваться

1. **Откройте снимок**: Ctrl+O или перетащите файл в окно. Удобнее всего снимок, где пыль хорошо видна:
   небо или ровная стена на закрытой диафрагме.
2. **Отметьте пятна**:
   - инструмент **Точка** (S): кликните по пятну. Круг должен быть чуть больше пятна вместе с мягким ореолом;
   - размер круга: `[` и `]`, Shift+колесо или ползунок;
   - **Кисть** (B): обведите мазком волосок, царапину или вытянутое пятно;
   - или нажмите **«Найти пятна»** и уберите лишние через ПКМ → «Удалить пятно».
3. **Проверьте результат**: клавиша `\` переключает «до/после», колесо мыши меняет масштаб, пробел или
   средняя кнопка двигают кадр. Цвет маркера показывает, какой метод сработал: голубой — «пыль»,
   жёлтый — «восстановление», зелёный — «заливка». Если результат не нравится, смените метод для этого пятна
   через ПКМ.
4. **Сохраните**: Ctrl+S. По умолчанию к имени файла добавляется `_clean`, исходник не перезаписывается.

### Пакетная обработка (Ctrl+B)
1. Отметьте пятна на одном снимке. При желании сохраните карту: «Файл → Сохранить карту пятен…».
2. Откройте «Пакетная обработка», добавьте файлы или целую папку (можно перетащить).
3. Настройки:
   - **Уточнять положение и размер** (включено по умолчанию). Пыль немного смещается и меняет размер
     в зависимости от диафрагмы и фокусного расстояния. Программа находит пятно рядом с отметкой на каждом
     снимке.
   - **Не трогать невидимые пятна**: на открытой диафрагме или на пёстром фоне пыль часто не видна,
     и такие места останутся нетронутыми.
   - **Дополнительно искать новые пятна**: на каждом снимке запускается автопоиск.
   - **Другая ориентация**: если среди снимков есть уже повёрнутые портретные кадры, карта поворачивается
     вместе с ними.
4. Результаты по умолчанию сохраняются в подпапку `cleaned` рядом со снимками.

### Консольный режим
```
DustHeal.exe --batch dust_map.json --out D:\Фото\clean D:\Фото\Поездка
DustHeal.exe --batch dust_map.json --skip-invisible --format .tif --workers 4 снимок1.jpg снимок2.tif
DustHeal.exe --autodetect --sensitivity 0.6 D:\Фото\Небо
```
Все параметры выводит `DustHeal.exe --help`.

## Как это работает (кратко)

- **Пыль на матрице** физически ведёт себя как полупрозрачная тень: она умножает свет на коэффициент меньше 1.
  Программа оценивает «чистый» фон гармонической интерполяцией с краёв пятна (мембрана Лапласа: самая гладкая
  поверхность, точно совпадающая с краем) и вычисляет карту ослабления. Карта сглаживается билатеральным
  фильтром: края тени остаются резкими, а текстура сюжета не «съедается». Затем изображение делится на карту.
  В результате под пятном сохраняются настоящие детали и зерно, а не их копия с соседнего места.
- **Плотные пятна, волоски, грязь**: из десятков участков вокруг выбирается донор, у которого лучше всего
  совпадают структура окружения, уровень шума и отсутствие посторонних деталей. Затем решается уравнение
  Пуассона, и цвет, яркость и контраст вставки плавно подстраиваются под границу пятна. Шва нет.
- **Плавная заливка**: гладкая мембрана по краю плюс зерно донора. Подходит для градиентов неба и воды.
- **Автопоиск**: морфологическое «закрытие» на пирамиде масштабов в логарифме яркости находит мягкие тёмные
  пятна. Фильтры по контрасту относительно локальной текстуры, по форме и по окружению отсекают детали сюжета.

Самопроверка на синтетическом небе с известным эталоном: `python tests/selftest.py`. Ошибка после обработки
0.4–0.8 единицы из 255, то есть ниже уровня шума самого снимка. До обработки было 12–29.

## Ограничения
- RAW-файлы напрямую не открываются. Обрабатывайте 16-битные TIFF из конвертера (Lightroom, Capture One,
  darktable) или используйте встроенные инструменты конвертера для своих RAW.
- Снимки показываются в ориентации матрицы, без поворота по EXIF. Это сделано специально: в таком виде пыль
  на всех кадрах находится в одних и тех же координатах. Тег ориентации при сохранении сохраняется.
- Для 16-битных PNG цветовой профиль не сохраняется (ограничение библиотек). Для 16 бит используйте TIFF.
- На экран выводится sRGB, без цветокоррекции под монитор.

## Структура проекта
```
app.py                     точка входа (GUI и консоль)
dustheal/core/heal.py      алгоритмы удаления (пыль, восстановление, заливка, авто)
dustheal/core/detect.py    автопоиск и уточнение положения пятен
dustheal/core/batch.py     пакетная обработка
dustheal/core/imageio.py   чтение и запись 8/16 бит, EXIF, ICC, пути Unicode
dustheal/core/spots.py     пятна и карты пятен (JSON)
dustheal/gui/              интерфейс (PySide6/Qt)
build.bat                  сборка DustHeal.exe
tests/selftest.py          самопроверка качества
```
